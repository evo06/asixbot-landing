[05 // ESPECIFICAÇÕES TÉCNICAS & PERGUNTAS FREQUENTES] ARQUITETURA · SEGURANÇA · IMPLANTAÇÃO

Respostas diretas para decisores técnicos.

Como o AsixBot garante que os dados da empresa não vazem para terceiros? +
Diferente de plataformas SaaS onde suas conversas, planilhas e senhas ficam salvas no banco de dados do fornecedor, o AsixBot grava todo o estado em um banco SQLite local (~/.asixbot/state.db) e protege credenciais com criptografia AES-256-GCM no chaveiro do próprio sistema operacional.
Como colocar o AsixBot em um servidor para vender automações para empresas? +
Basta provisionar uma VPS Linux (Hetzner, AWS, DigitalOcean ou servidor local da empresa) e executar o instalador headless. O AsixBot sobe como um serviço systemd com display virtual Xvfb para o navegador Chromium e expõe o workspace protegido por autenticação para toda a equipe do cliente.
Posso rodar modelos 100% gratuitos e offline sem pagar API da OpenAI ou Anthropic? +
Sim. O AsixBot possui integração nativa com Ollama e vLLM, permitindo que unidades como o AEGIS e o KRONOS utilizem Llama 3.3, Qwen 2.5 Coder, DeepSeek R1 ou Mistral diretamente na GPU local com custo zero por token.
Como funciona a automação de portais e ERPs que não possuem API? +
A unidade VORTEX controla uma instância real do Chromium via protocolo CDP (Chrome DevTools Protocol). Ela lê a árvore DOM e a interface visual, realiza login usando credenciais injetadas pelo cofre, baixa relatórios e salva os artefatos diretamente na pasta compartilhada do workspace.
